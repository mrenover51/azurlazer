# AZUR LASER

Site vitrine d’AZUR LASER, entreprise spécialisée dans le décapage laser et
l’aérogommage.

## Stack

- Next.js avec App Router
- TypeScript
- Tailwind CSS
- ESLint

## Développement

```bash
npm install
npm run dev
```

Le site est ensuite disponible sur [http://localhost:3000](http://localhost:3000).

## Navigation prévue

- Accueil
- Décapage laser
- Aérogommage
- Réalisations
- Zone d’intervention
- Contact / Devis
